# Продуктовая аналитика интернет-магазина

Сквозной проект: от загрузки данных до дашборда.

## Данные
- RetailRocket: kaggle.com/datasets/retailrocket/ecommerce-dataset
- Cookie Cats: kaggle.com/datasets/mursideyarkin/mobile-games-ab-testing-cookie-cats

Датасеты кладутся в папку data/ и в репозиторий не коммитятся.

## Что внутри
- Воронка view -> корзина -> покупка, конверсия
- DAU/MAU и retention по когортам
- A/B-тест размещения гейта (z-тест долей)
- Дашборд в Yandex DataLens

## Стек
Python (pandas), REST API, Google Sheets, Yandex DataLens, Git
